# Meeting Notes Summarizer

Paste meeting notes (or upload a `.txt` file) and get an executive summary, a list of action items, and the attendees, all generated locally with no API keys or usage costs.

## Features

- **Executive summary** generated by Facebook's BART-large-CNN model
- **Handles long transcripts:** notes are split into sentence-aligned chunks so meetings longer than BART's input limit still get summarized
- **Action items** pulled out with keyword rules ("will", "needs to", "follow up", "deadline", ...)
- **Attendees** read from an `Attendees:` or `Present:` line
- Paste text or upload a `.txt` file
- One-click download of the summary and action items
- Runs entirely on CPU on your own machine

## How it works

```
Notes -> split into ~1,000-character chunks on sentence boundaries
      -> summarize each chunk with BART-large-CNN
      -> join chunk summaries into one executive summary

Notes -> scan lines for action keywords   -> action items (top 10)
      -> find "Attendees:" / "Present:"   -> attendee list
```

BART can only read about 1,024 tokens at a time. Chunking on sentence boundaries keeps each piece under that limit without cutting sentences in half.

## Tech stack

| Component     | Tool                                  |
|---------------|---------------------------------------|
| Summarization | `facebook/bart-large-cnn` (HuggingFace Transformers) |
| Backend       | PyTorch (CPU)                         |
| Interface     | Streamlit                             |

## Setup

```
git clone https://github.com/Khokon0123/meeting-summarizer.git
cd meeting-summarizer
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

The first run downloads the BART model (about 1.6 GB). Try it with `sample_meeting.txt`.

## Limitations

- Action items and attendees are found with simple rules, so unusual phrasing can be missed or picked up by mistake.
- Chunk summaries are joined directly, so very long meetings can produce a summary with some repetition.
- Summarizing on CPU takes a few seconds per chunk.

## Possible improvements

- Use an LLM or a named-entity model for more reliable action items, owners, and deadlines
- Run a second summarization pass over the combined chunk summaries
- Support audio input with Whisper transcription
